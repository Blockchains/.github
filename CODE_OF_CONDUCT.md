# Code of Conduct

We adopt the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive; no harassment, discrimination, personal attacks, doxxing or spam (including token shilling and scam links). Maintainers may remove content and block accounts that violate this code.

**Reporting:** open a private report via a [GitHub security advisory](https://github.com/Blockchains/blockchains.github.io/security/advisories/new) marked "Code of Conduct", or use GitHub's built-in [report abuse](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam) tools. Reports are handled confidentially.
