# Blockchains/.github

Default community health files (issue & PR templates, CONTRIBUTING, CODE_OF_CONDUCT, SECURITY, FUNDING) for every repository under [github.com/Blockchains](https://github.com/Blockchains) that does not define its own.

→ Start at the **[Blockchain Lab Hub](https://blockchains.github.io/)**.

**Build with blocks:** [docs/BUILD-WITH-BLOCKS.md](docs/BUILD-WITH-BLOCKS.md) explains how an AI agent or a human assembles a project from Blockchains repos (3 verified end-to-end recipes). Every live repo ships `AGENTS.md`, `llms.txt` and a `blocks.json` manifest ([schema](docs/BLOCKS-SCHEMA.md), validated by [validate-blocks](.github/workflows/validate-blocks.yml)); the aggregated catalogue is at [blockchains.github.io/blocks.json](https://blockchains.github.io/blocks.json) and the org doc map at [blockchains.github.io/llms.txt](https://blockchains.github.io/llms.txt).

Latest end-to-end test and documentation audit of every Blockchains repo: **[docs/STATUS.md](docs/STATUS.md)**.
